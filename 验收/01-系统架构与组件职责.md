# 系统架构与组件职责

## 要证明的规则

- 接入层受理路径不执行图。
- 消息投递只把调度送出去，不改执行权，也不改任务终态。
- Worker 不做全局恢复扫描。恢复扫描是 Runtime 里的另一个角色。
- Redis 不保存执行权。Milvus 不保存任务。假写所用的 MySQL 不保存任务执行权。
- Kafka offset 提交只表示消费位置，不表示任务完成。
- 假业务目录和底座目录分开，假业务代码不引用底座的任务表。
