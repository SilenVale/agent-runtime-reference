# 常见架构面试题与回答要点

公开仓库不放面试题对照，也不放简历条目。这一章只核对：每一题都能指到已经通过的测试，或指到 `docs/架构.md` 的段落。

## 要证明的规则

下面 24 题都有证据。证据要么是前面章节里已经通过的测试名，要么是架构文档里的小节。

1. 为什么需要独立的 Agent Runtime，而不是直接在请求线程里调用 Agent？
   证据：`接入层受理路径不执行图`；架构「三个进程」
2. Worker、业务 Agent 和执行适配器分别负责什么？
   证据：架构「Worker」；架构「执行适配器」；架构「业务图」
3. 为什么同时使用 PostgreSQL、Checkpoint、对象存储和 Milvus？MySQL、Redis 必须有吗？
   证据：`Redis与Milvus与MySQL不保存任务执行权`；架构「存储归属」
4. 为什么使用 Kafka？能否直接轮询数据库调度？
   证据：`投递器在确认前退出会用原消息ID再投`；架构「Kafka」
5. 客户端超时重试，怎样避免重复创建任务？
   证据：`同键同参返回原任务且同键异参冲突`
6. Outbox 解决什么问题？为什么仍会重复投递？
   证据：`投递器在确认前退出会用原消息ID再投`
7. Worker 应该什么时候提交 Kafka offset？
   证据：`offset提交不表示任务完成`；`T2提交前退出允许再消费且offset已提交后改由租约恢复`
8. event_id、dispatch_seq、epoch、operation_id 有什么区别？
   证据：架构「六个标识」；`T1同时提交任务幂等键受理事件和Outbox并返回202`
9. 有租约，为什么还需要 epoch？
   证据：`旧epoch提交被拒绝且数据库时钟判断租约`
10. 为什么新 Worker 不能直接读取旧线程的最新 Checkpoint？
    证据：`旧线程新存档不能登记为当前恢复引用`
11. 业务写成功，但 Worker 在记录结果前退出，如何避免重复操作？
    证据：`超时后按原operation_id查询假写且不写第二次`
12. 为什么 Kubernetes 重启 Pod 不能代替任务恢复？
    证据：`Worker不承担全局恢复扫描`；`Worker全部退出时恢复扫描仍能登记Outbox`
13. 如何生成稳定的 operation_id？为什么参数摘要不能直接作为它？
    证据：`operation_id在调用前固定且重试不换号`；`同一定位换参数被拒绝`
14. 工具调用超时后，应不应该自动重试？
    证据：`写工具超时按原operation_id查询且不自动重写`
15. 为什么任务取消不等于业务回滚？
    证据：`取消不把已发出的假写当成已回滚`
16. 人工审批等待应该怎样持久化和恢复？
    证据：`WAITING到期不自动当成已批准`；`人工等待到期不自动批准`
17. 并行分支如何共享预算，故障后如何继续计费？
    证据：`预算跨接管仍累计且旧代次不能覆盖`；`相同call_id重复结算不重复扣费`
18. MCP 在架构中解决什么？哪些能力不是它自动提供的？
    证据：架构「MCP 出站」；架构「入站 MCP」；`入站断线不取消已受理任务`
19. 如何避免模型或检索内容绕过工具权限？
    证据：`未进工具闸门的调用不能发出`；`工具发现结果未过闸门不能成为可调用工具`
20. conversation_id、task_id、thread_id 如何区分？上下文缓存丢失怎么办？
    证据：`会话记录不能代替任务状态或操作账本`；架构「Redis」
21. SSE 如何支持断线重连和多副本？能保证恰好一次吗？
    证据：`断线后按event_seq补读且重复投递由客户端游标去重`；`任一接入层副本都能读到已提交事件`
22. 为什么 Kafka 积压为零，Worker 仍可能很忙？如何扩缩容？
    证据：`offset提交不表示任务完成`；`执行槽位为0时恢复扫描仍能登记Outbox`
23. 如何避免单租户占满资源？额度不足时怎样延期？
    证据：`额度不足不授予owner并留下延期调度`；`单租户额度不足时不占住其他任务的接管`
24. 滚动发布或故障后，怎样让存量任务继续执行？
    证据：`缩容时未完成交接的任务仍可从恢复点继续`；`确认后图启动前退出`
